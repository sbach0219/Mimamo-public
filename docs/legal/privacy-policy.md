みまも（Mimamo。以下「本アプリ」）は、外出する人（「歩く人」）と、その人を見守る人（「見守る人」）が、安全のために現在地などをリアルタイムで共有するためのアプリです。本ポリシーは、本アプリが取得・利用・保管する情報について、個人情報保護法その他関連法令に沿って説明するものです。

## 2. 個人を特定する情報は取得しません

本アプリは、**氏名・メールアドレス・電話番号・住所・生年月日などの個人を特定する情報を、登録項目として一切取得しません。**アカウント登録・ログイン操作は不要です。

利用者の識別には、端末ごとに自動生成される**匿名のランダムなID**（Firebase Authentication の匿名認証）のみを使用します。このIDは端末にひもづくものであり、氏名等の登録情報と結びついていないため、このIDから運営者が利用者個人を特定することはできません。

**継続的に見守り合う相手を設定する場合（以下「見守りペア」）、次の情報を任意で登録できます。** これらは氏名の登録を求めるものではありませんが、利用者ご自身が自由に入力・選択する情報であるため、結果として実名に近い呼び名を入力することも技術的には可能です。登録した表示名・アバターは、**見守りペアの相手にのみ表示され**、運営者が第三者へ開示することはありません。

- **表示名（ニックネーム）**: 見守りペアの相手が識別するための呼び名。本名の入力は必須ではありません。
- **アバター**: あらかじめ用意された絵柄からの選択のみです。写真のアップロードはできません。

これらの情報は匿名ID（`users/{uid}`）に紐づけて保存されます。運営者側からの読み取りはできず、匿名IDに紐づく文書はご本人のみが読み取れる設計です。表示名・アバターは、見守りセッション終了後7日で自動削除される情報（6項参照）とは異なり、**ご本人が編集・削除するか、見守りペアを解除するまで保存され続けます。** また、見守る人が入力する「見守り対象の呼び名・年齢（年齢は任意）」については7項で説明します。保存期間の詳細は6項をご覧ください。

面識のある見守りペアの相手には、あなたが設定した表示名・アバターが表示されるため、**「どなたの情報か」がわかる場合があります。** これは第三者への開示ではなく、ご本人が見守り関係を結んだ相手への表示です。

## 3. 取得・利用する情報

本アプリは、見守り機能を提供する目的に限り、以下の情報を取得・利用します。

| 情報 | 取得する場面 | 利用目的 |
|------|------------|---------|
| 現在地（位置情報） | 見守りセッション中（「歩く人」のみ） | 見守る人にリアルタイムで現在地を届けるため |
| バックグラウンドの位置情報 | 見守りセッション中、アプリを閉じている間（「歩く人」が位置情報を「常に許可」した場合のみ） | アプリを開いていない間も見守りを継続するため |
| 移動経路（位置情報の履歴） | 見守りセッション中 | 見守る人が歩いた道のりを地図上で確認できるようにするため。この記録はセッション終了後も残ります（6項参照） |
| 自宅など目的地の位置（任意） | 見守る人が設定した場合のみ | 「歩く人」が目的地に到着したことを自動で検知するため |
| GPSから算出される移動速度 | 見守りセッション中（「歩く人」のみ） | 乗り物特有の速さでの移動など、異常のパターンを検知するため。**この値は端末内の判定にのみ使い、サーバーへは送信・保存しません。** |
| チャットのメッセージ | 利用者が送信したとき | 歩く人と見守る人の間で連絡を取り合うため |
| 端末の電池残量・充電状態 | 見守りセッション中（「歩く人」のみ） | 見守る人が「歩く人」の端末の電池切れ・充電状況を把握できるようにするため |
| モーション（加速度）センサーの値 | AI見守りモードの利用中、アプリが前面にある間（「歩く人」のみ） | 転倒の可能性を検知するため。**値は端末内（オンデバイス）でのみ解析し、サーバーには送信しません。** |
| 見守りセッションの設定内容 | セッション作成時 | 予定時間、見守りモード（おまもりボタン／AIおまかせ）、AIの感度、移動手段（徒歩／乗り物利用可）の宣言など、見守りの動作に反映するための設定情報 |
| 異常検知・SOS・安否確認のイベント記録 | 異常を検知したとき、SOSを発信したとき、安否確認のやり取りをしたとき | 検知の種類（停滞・転倒・移動の異常など）や発生時刻を記録し、見守る人への通知や状況の記録に使うため |
| プッシュ通知トークン（FCM）・最終起動時刻（lastSeenAt） | アプリ起動時、通知を許可したとき | SOS・到着・メッセージなどの通知を届けるため。見守りペアの相手と長期間連絡が取れなくなっていないかを判定するため（相手には通知の可否のみが影響し、時刻そのものは表示されません） |
| 表示名（ニックネーム）・アバター（任意） | 見守りペアの設定・編集時 | 見守りペアの相手が識別できるようにするため。相手にのみ表示されます |
| 見守りペアの関係情報（誰と誰が見守り関係にあるか。当事者の匿名IDの組み合わせ・ペアの状態） | ペアの招待・成立・解除時 | 招待手続きなしで見守りを始められる継続的な関係を維持するため。**この関係は「位置情報を常時取得・共有する権利」ではありません。位置情報の共有は、歩く人が個別の見守りセッションを開始している間に限られます。** |
| 見守り対象の呼び名・年齢（任意。見守る人が入力） | 見守りペアの設定・編集時 | 緊急時に見守る人が相手の情報を伝えられるようにするため。7項もあわせてご覧ください |
| 直近の見守りの終了時刻・最終状態・行き先のラベル（例:「学童保育室に到着」）・地名の文字列（例:「東京都 世田谷区 三軒茶屋」） | 見守りセッション終了時 | 見守りペアの一覧に「まえの見守り: 15分前・東京都 世田谷区 三軒茶屋」のように表示するため。**座標・移動経路・電池残量はこの記録に含まれません。地図上のピンとしても表示されません。** 行き先のラベルは利用者が入力した文字列、地名の文字列は端末が座標から変換したものです |
| 月額サブスクリプションの購入資格（エンタイトルメント） | プランの購入・更新・復元時 | グループ見守り（複数人の同時見守り・見守りペア）機能の利用資格を管理するため |

**位置情報は、見守りセッションが有効な間だけ取得します。** セッションを終了すると、新たな位置情報の取得は停止します（すでに記録された経路は6項のとおり保存され続けます）。**見守りペアが成立している場合でも、位置情報が常時共有されることはありません。**

**モーションセンサーの値は端末内でのみ解析し、サーバーには送信しません。** サーバーに記録されるのは「転倒の可能性を検知した」というイベントと、その時点の位置情報のみです。AI見守りモードを使わない場合、モーションセンサーは利用しません。

**見守り中は、見守る人の画面に「〇〇付近」のような地名を表示するために、現在地を地名へ変換する処理（逆ジオコーディング）を行うことがあります。** これは緊急時に限らず、通常の見守り中にも行われます。変換処理はOSが提供する位置情報機能（iOS/Androidの地図機能）を通じて行われ、座標そのものを外部の変換サービスへ送ることはありません。

変換後に得られる地名の文字列は、原則として画面表示のために短時間利用するだけですが、**見守りペアを設定している場合に限り、「最後にどのあたりで見守りが終わったか」を見守る人の一覧に表示するために、地名の文字列（例:「東京都 世田谷区 三軒茶屋」）を見守りセッションの記録および見守りペアの記録へ保存します。** 保存されるのは地名の文字列と時刻だけで、座標・移動経路・電池残量は含まれません。この地名は地図上のピンとしては表示されず、最後の更新から7日が経過すると自動的に消去されます（6項）。

## 4. 情報の共有範囲

- 上記の情報（位置情報・経路・メッセージ・電池残量など）は、**同じ見守りセッションに参加している相手（歩く人⇔見守る人）との間でのみ共有されます。**
- 見守りセッションは、共有用リンクを知っている人だけが参加できます。リンクは推測困難なランダムなIDで構成されています。リンクを本人の同意なく第三者へ渡すと、その第三者がセッションに参加できてしまうため、リンクの取り扱いにはご注意ください（利用規約もあわせてご確認ください）。
- **見守りペアの表示名・アバター・見守り対象の呼び名や年齢・直近の見守り状況は、そのペアの相手にのみ共有されます。** 見守りペアの成立には、当事者双方の同意（招待の作成・受諾の操作）が必要です。ペアが成立すると、双方に通知されます。
- **広告目的での第三者提供、情報の販売は一切行いません。**
- 本アプリは広告を表示しません。また、広告SDKや、行動追跡（トラッキング）・解析（アナリティクス）のためのSDK・データ収集は組み込んでいません。
- **月額サブスクリプション（グループ見守り機能）の購入管理には、RevenueCat（購入管理サービス）を利用します。** RevenueCatへ渡るのは、匿名IDに相当する識別子と購入・購読の情報のみであり、**位置情報・チャット・表示名・見守りペアの情報などは一切渡りません。** クレジットカード番号等の決済手段の情報は、Apple App Store／Google Playが処理し、運営者・RevenueCatのいずれも取得・保存しません。

## 5. 情報の保管とインフラ

本アプリは、データの保管・通信に Google が提供する Firebase（Google Cloud Platform）を利用します。

- Firebase Authentication（匿名認証）
- Cloud Firestore（セッション・位置・メッセージ・見守りペア・プロフィールの保管）
- Firebase Cloud Messaging（プッシュ通知）
- Cloud Functions（通知の送信処理。東京リージョン〔asia-northeast1〕で稼働）
- RevenueCat（月額サブスクリプションの購入管理。位置情報などは渡りません。詳細は4項）

これらのインフラは Google のセキュリティ基盤により保護されます。Google のプライバシーポリシー: https://policies.google.com/privacy／RevenueCat のプライバシーポリシー: https://www.revenuecat.com/privacy

なお、Google のインフラの構成上、データが日本国外のサーバーを経由・保管される可能性があります。この点は今後、実際のFirestoreのデータ保存リージョン設定を確認のうえ、必要であれば記載を精緻化します。

## 6. データの保管期間と削除

- 見守りセッションの記録（現在地・移動経路・チャットメッセージ・異常検知の記録などを含みます）は、機能提供およびアプリ内の「履歴」機能のため、見守りセッションが終了するまでの間、Cloud Firestore に保管されます。
- **見守りセッションが終了した（「終了」「到着」「取消」のいずれかになった）時点から7日が経過すると、当該セッションの記録（チャットメッセージ・移動経路の履歴を含みます）は、サーバー側の自動処理により Cloud Firestore から完全に削除されます。** この自動削除は日次バッチ（毎日1回、日本時間4時）で実行されます。いつ終了したかが確認できないセッションや、見守りが進行中のセッションは削除の対象になりません（安全側に倒す設計とし、判断がつかないデータは消さない方針としています）。
- 保管期間（7日）より前に記録の削除をご希望の場合は、本ポリシー記載の連絡先（contact@thousandsky.com）にご依頼ください。ご依頼の際は、アプリ内の設定画面等で確認できる匿名ID、またはセッションのおおよその日時をお知らせください。**現時点ではアプリ内に自己完結型の削除機能はなく、7日の自動削除を待たずに削除したい場合は、運営者が確認のうえ個別に対応します。**
- アプリを端末から削除すると、その端末に保存されたローカルデータ（進行中セッションの一時情報など）は削除されます。ただし、すでにサーバー（Cloud Firestore）に送信済みの記録は、上記の自動削除（7日後）または個別の削除依頼によるまで残ります。

**見守りペア（表示名・アバター・ペア関係・見守り対象の呼び名や年齢・直近の見守り状況）の保管期間は、上記の見守りセッションの記録とは異なる区分です。**

- 表示名・アバターは、匿名IDに紐づけて保存され、アプリ内の「プロフィール」画面からいつでも編集・空欄にできます。**匿名IDに紐づく文書そのもの（`users`）を削除する専用のボタンは、本改定時点ではアプリ内にまだ実装していません。** ご依頼の場合は連絡先（contact@thousandsky.com）へご連絡ください。
- 見守りペアの関係・見守り対象の呼び名や年齢は、**ペアが有効（active）である間保存され、いずれかの当事者がペアを解除した時点（revoked）から7日が経過すると、直近の見守り状況とあわせて自動的に削除されます。** 見守り対象の呼び名や年齢は、ペアの解除操作によっても削除されます。
- **見守りペアは、歩く人・見守る人のいずれからでも、アプリ内の「つながり」画面（設定タブから遷移できます）から、いつでも一方的に解除できます。** 特に、見守り対象となる「歩く人」は、いつでも自らの意思で見守りペアを解除できます。**ペアが解除されると、相手方に通知されます。**
- **解除の時点で進行中の見守りがある場合、その見守りもその場で終了し、位置情報の共有は直ちに停止します。** 解除は「これから見守りを始められなくする」だけでなく、「いま流れている位置情報を止める」操作でもあります。
- 直近の見守り状況（時刻・最終状態・行き先のラベル・地名の文字列）は、**最後の更新から7日が経過すると自動的に消去されます。** 手動で個別に消去する機能は、本改定時点ではアプリ内にまだ実装していません。
- 見守りペアが有効な状態そのものは、位置情報を継続的に取得・共有するものではありません。**位置情報の共有は、歩く人が個別の見守りセッションを開始している間に限られ、この点は見守りペアの導入後も変わりません。**座標・移動経路・チャットの7日自動削除ルールも変わりません。

## 7. 子どものプライバシー

本アプリは、保護者・支援者が子どもや高齢者を見守る用途を想定していますが、本アプリ自体が氏名・連絡先等、個人を特定する情報を取得することはありません。子どもが「歩く人」として本アプリを使う場合も、取得する情報は3項の内容（位置情報・チャット等）に限られます。

未成年の方が本アプリを利用する場合、見守りセッションの作成（本ポリシー・利用規約への同意を伴う操作）は、保護者等の大人が行うことを想定しています。

見守りペアの表示名・アバターおよび見守り対象の呼び名・年齢を設定する場合、**お子様の本名ではなくニックネームの入力を推奨します。** これらは、保護者等の大人がお子様に代わって入力・編集することを想定した設計です。

## 8. 権限（パーミッション）について

本アプリが端末に求める主な権限と理由は以下のとおりです。

- **位置情報（使用中／常に）**: 見守る人に現在地を届けるため。「常に許可」は、アプリを閉じている間も見守りを継続するために必要です。「使用中のみ許可」の場合、アプリを閉じる（または画面をロックする）と位置の共有が止まります。
- **モーションとフィットネス（モーションセンサー）**: AI見守りモードで転倒の可能性を検知するため。値は端末内でのみ解析し、外部には送信しません。
- **通知**: SOS・到着・メッセージなどの重要なお知らせを届けるため。
- **バイブレーション**: 通知をお知らせするため。

マイク（録音）の権限は要求しません。SOS発信時に警告音を再生する機能がありますが、これは音声の再生のみであり、録音は一切行いません。

「常に許可」でバックグラウンド位置情報を使用している間、Android では「みまも 見守り中」という通知が常時表示され、iOSではOSの標準機能により位置情報の利用中インジケーターが表示されます。これは、見守り中であることをご本人にも分かるようにするための仕様です。

これらの権限はいつでも端末の設定から変更できます。ただし位置情報を無効にすると、見守り機能は利用できません。

## 9. 有料機能・お支払いについて

本アプリは、複数人を同時に見守る機能・恒久的な見守りペア機能を「グループ見守り」として、月額サブスクリプションで提供します。

- お支払いは Apple App Store／Google Play の課金基盤を通じて行われます。**クレジットカード番号等の決済手段の情報は、Apple／Google が処理し、運営者は取得・保存しません。**
- 購入・購読の管理には RevenueCat を利用します。運営者・RevenueCatが保存するのは、購入したプランの種類・有効期限・購入資格（エンタイトルメント）の状態のみで、**位置情報・チャット・見守りペアの情報などは渡りません。** 詳細は4項・5項をご覧ください。
- **SOS発信・異常検知・到着通知・チャットなどの安全にかかわる機能は、すべて無料でご利用いただけます。** 月額サブスクリプションの有無によって、これらの安全機能の提供内容が変わることはありません。有料になるのは、同時に見守れる人数の拡張と、恒久的な見守りペア機能のみです。
- 返金・キャンセルについては、購入元（App Store／Google Play）の規定に従います。

## 10. セキュリティ

本アプリは、Cloud Firestore のセキュリティルールにより、見守りセッションの参加者（歩く人・見守る人）以外がデータを読み書きできないようアクセスを制限しています。見守りペアの匿名ID・プッシュ通知トークンを含むプロフィール文書（`users`）は、ご本人以外は読み取れません。通信は暗号化された経路（TLS）で行われます。
