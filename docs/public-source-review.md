### 残存するHigh: image-size（Metro経由）

特殊なICNS/JXL/HEIF画像の解析で無限ループになる問題です。
`metro/src/Assets.js` がビルド時の画像処理に使用します。公開ソースに含まれる
信頼できる画像でのビルドと、第三者が持ち込む画像のビルドは区別してください。
未知の画像を扱うCIには実行時間制限を設けてください（付属CIは制限あり）。
この確認では、モバイル実行時に同じパーサーへ外部画像を渡す経路は特定していません。
Metroが要求する1.xには修正版がなく、APIが異なる2.xへの強制上書きは行っていません。

- https://github.com/advisories/GHSA-w3rx-r6r6-pgpr
- https://github.com/advisories/GHSA-5p2g-fcmc-qvqq

### 残存するModerate: uuidとその依存元

`uuid` のv3/v5/v6に出力バッファを渡す場合の境界チェックに関する問題です。
ExpoのXcodeプロジェクト生成処理は `xcode/lib/pbxProject.js` でv4を使用しており、
その呼び出しは当該条件に該当しません。Functions側でもFirebase AdminとGoogle Cloud
ライブラリの依存として残ります。全推移依存の到達可能性まで保証するものではありません。
Firebase Adminのメジャー更新やExpoのダウングレードは、公開準備に混ぜて実施していません。

- https://github.com/advisories/GHSA-w5hq-g745-h8pq
